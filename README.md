PowerHour — Kill Your Electricity Bill ⚡

**PowerHour** is a professional-grade energy cost estimator that helps users track, visualize, and slash their electricity expenses. By breaking down power consumption by appliance, it identifies "Energy Hogs" and provides actionable data to save money.
  🚀 Key Features
- **Real-Time Calculation**: Dynamic cost estimation based on wattage and usage hours.
- **Localized Presets**: Support for multiple currencies (including GHS, USD, NGN) and country-specific kWh rates.
- **Visual Analytics**: Interactive bar charts for cost breakdown and high-intensity appliance alerts.
- **Privacy-First**: All data is stored locally via the `LocalStorage API`—your utility data never leaves your browser.
- **Adaptive UI**: High-contrast dark mode with a responsive, "electric" aesthetic.
